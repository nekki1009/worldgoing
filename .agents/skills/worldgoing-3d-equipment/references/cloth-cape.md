# 長披風與離身軟布

適用長披風、袍裙等輪廓離開人體的柔性部件。沿用使用者指定的裝備、素體與骨架；此文件不授權增加人體骨骼、物理系統或額外角色款式。

## 輪廓與來源

將參考拆成受力點、主布、肩披、領座、開襟、內裡和下襬。量測当前 Rest Pose 的肩頸／胸背與內甲包絡；參考透視圖只提供比例和結構，尺寸以穿戴結果判斷。

主布應有環身的連續曲面或可說明的縫合裁片；由肩頸向下分配布量，形成主褶、展襬與重力垂墜。程序化網格可作起點，但均勻正弦波與前側後直板不足以交付。保留可編輯 `.blend`；builder 匯入已完成部件，避免每次建置沖掉形狀調整。

先交灰模正／背／左右／3⁄4：穿戴輪廓應已像參考；領子有前開口且可見，肩披連接肩背，主襬長度與展開量合理。未達標時先修曲面，暫緩刺繡和扣具。

內裡從完整外殼推導，保持對應邊界、法線方向及形變；可用內外材質面和薄邊緣，不以兩條紅色前板或窄下襬冒充完整內裡。外露翻邊與褶皺應在單件內面圖也成立。

薄雙層布面彎折時，內外四邊形若被匯出器選用不同對角線，可能出現紅黑碎片交錯。需使用對應的三角剖分，並在變形後重新推導內面間距；只增加面数或翻法線不能修好這類錯誤。

## 動作

柔性肩披不能整片剛性綁上臂。肩領受力区以胸肩蒙皮開始，其他區域以實際姿態校正；硬扣具才用既有剛性 helper。不要將整張披風直接轉印成左右腿權重，也不要將所有低處頂點 100% 指派骨盆。

先用一個短循環證明 Blender → GLB → Godot 的蒙皮及形態校正會同步播放、暫停、seek、重設和循環。Cloth 模擬可作垂墜與形變來源，最終須有經實測可匯出的蒙皮或 morph 資料；模擬快取本身不是遊戲動畫。

至少檢查左右最大跨步、前傾、抬臂、扭身與任務要求的跳躍／騎乘。檢查肩縫、臀腿、鞋與馬背接觸；前襟留有腿部活動空間，下襬不能隨腿黏成褲管。對每個已支援動作保留完整短片或可播放序列，另列極值幀和未測組合。

轉身動作的蒙皮與修形插值不等於線性空間運動。稀疏取樣可能在取樣幀合格、兩幀之間仍穿出膝部；檢查中間幀，按曲率與動作速度增加取樣，並保留布量間隙。避免把個別頂點直接投影到膝蓋，造成尖刺與自交。

本案 Blender 4.2 的既有動作已烘焙：關閉 `export_force_sampling` 並開啟 `export_optimize_disable_viewport` 可避免所有披風修形在每個骨骼取樣點反覆更新。這不是所有來源的通用設定；仍需核對原動作、非目標網格、skin 綁定及實際 Godot 播放。使用相同 NLA track 名稱合併骨骼與 morph，必須實查 GLB 動畫 channel，而非只開啟匯出勾選。

## 材質與檢視

先驗證一片有 UV 的材質樣片：外布、內裡、金屬及薄繡線應在 Godot 可辨認。大褶用幾何，細織紋與刺繡用貼圖。先核對 Toon 紋理傳遞和描邊尺度；描邊比金線還厚時，應調整細節描邊路由。

使用完整解析度的角色 viewport 圖，另外保留 UI 選中目標的證據。切動畫可能重設相機，先完成模型／動畫／seek，再設美術相機。遊戲比例圖用原投影契約，不拿數十像素高的人物圖驗收接縫與穿模。

本次失敗反例：`.visual_captures/chinese_cape_showcase/male_chinese_cloak_collar_close.png` 有翻起的矩形肩片；`female_chinese_cloak_run.png` 人物太小不可判讀。這些圖說明品質檢查失效，不是可沿用的合格基準。
